# Environment Variables

# Nomic Atlas access requires an API key.

# .env file.
#
# Create a file named:
#
#     .env
#
# in the project root and add:
#
#     NOMIC_API_KEY=your_api_key_here
#
#
# The .env file is a local configuration file of author's API key and is not
# included in this repository.
